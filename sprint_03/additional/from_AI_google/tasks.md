### Задача «Слияние двух списков»:

_01_merge_two_lists.py_

Даны два уже отсортированных списка чисел. Нужно написать рекурсивную функцию, которая сливает их в один общий отсортированный список.

Пример:

Ввод: [1, 3, 5] и [2, 4, 6]

Вывод: [1, 2, 3, 4, 5, 6]

Условие:

Нельзя использовать встроенный sorted() или метод .sort(). Нужно сравнивать первые элементы списков и с помощью рекурсии строить новый.

Подсказка:

Базовый случай — если один из списков пуст, результатом будет другой (оставшийся) список. В ином случае сравниваем первые элементы list1[0] и list2[0], забираем меньший и вызываем рекурсию для «хвостов».
